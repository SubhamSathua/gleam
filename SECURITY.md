# Security Policy

## Supported Versions

The following versions of Gleam are currently supported with security updates:

| Version   | Supported |
| --------- | --------- |
| 1.0.0-pro | Supported |

## Reporting a Vulnerability

If you find a security vulnerability, please do NOT open a public issue. Publicly disclosing a vulnerability can put users at risk.

Report security vulnerabilities directly by contacting the maintainer via:
[contact.hefty730@slmail.me](mailto:contact.hefty730@slmail.me)

Alternatively, report private vulnerabilities using GitHub's built-in private vulnerability reporting:
[GitHub Security Advisories](https://github.com/SubhamSathua/gleam/security/advisories)

We will acknowledge your report and work to address confirmed vulnerabilities in the next maintenance release.

## Distribution & Malware Disclaimer

The author of this project only provides source code and official APK releases through authorized channels (e.g., this GitHub repository).

- **Official Builds:** Only releases published directly by the original maintainer on GitHub Releases are official Gleam builds.
- **Third-Party Distributions:** We are not responsible for versions of this software downloaded from other websites, mirrors, or repackaged stores.
- **Modified Versions:** If you download a version that has been modified or recompiled by someone else, you do so at your own risk.
